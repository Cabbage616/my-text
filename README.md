# 关于瑞泰

## 企业概况

### 企业简介

1. 西安瑞泰建材科技有限公司成立于2011年，聘请意大利高级工程师并联合国内专家组建了一支具有欧洲技术与中国技术相结合的专业技术团队，为客户提供砖瓦生产工艺设计、工程总承包、机械制造、设备供应及生产运维等全方位专业服务。公司致力于推动砖瓦行业技术进步，引领行业发展方向。

2. 西安瑞泰业务范围：
   - **设计与工程**：
     - 提供全自动砖瓦厂工艺设计及施工建设，涵盖室式/隧道式/快速干燥、隧道窑等。
     - 重点承建干燥室与窑炉工程，保障项目技术达标与产能目标。
   - **机械制造与供应**：
     - **成型包装线**：切坯机、码垛机、全自动卸料打包/包装机、冷拉伸罩膜包装机。
     - **窑炉自动化**：摆渡车、鼓风机、步进机、顶车机、窑车等。
     - **燃烧系统**：气体（天然气/LPG/煤气）、液体（重油/废轮胎油）、固体（煤粉、石油焦、稻壳、棕榈仁壳、椰子壳、棉籽壳等）。
   - **运维保产服务**：
     - 提供砖厂生产调试、运维及保产服务，助力用户轻松稳定生产。

# 产品

## 原料处理设备

- 皮带式箱式给料机：用于接收物料的料斗采用钢板焊接而成，设备钢架结构非常结实牢固,全部由H型钢焊接而成，配备硬齿面K系减速机，配有可以调整控制物料流量的闸门，以控制给料量的均匀性。
- 链板式箱式给料机：是一种用于黏土烧结砖行业的物料输送设备。它主要由头部机架、头部护罩、主动链轮组、输料装置、中部机架、尾部机架、改向链轮组、链板托轮组和驱动装置等组成。
- 双齿辊破碎机是：黏土烧结砖原料预处理的关键设备，通过两个相对旋转的齿辊对黏土、页岩或煤矸石进行剪切、挤压破碎，将原料粒度控制在3-10mm，满足后续搅拌和挤出工艺要求。
- 锤式破碎机：以冲击形式破碎物料的一种设备，分单转子和双转子两种形式。是直接将最大粒度为600-1800毫米的物料破碎至25或25毫米以下的一段破碎用破碎机。该设备用于原料的破碎，设备用途:单段破碎机主要适用于破碎抗压强度≤150MPa 的石灰石、泥灰岩、砂岩、页岩、煤等原料。
- 圆盘筛式给料机：一种集筛分与计量喂料功能于一体的集成化供料系统。其核心部件为配备可调节刮板的旋转盘和内置筛网（黏土砖生产通常采用3-10mm孔径），在向挤出机或搅拌机输送均质物料的同时，能有效剔除超标颗粒。
- 湿式轮碾机：黏土砖生产中的核心设备，用于将黏土原料与水进行破碎、混合、均化，形成可塑性泥料，确保颗粒细度和湿度符合挤出成型要求。
- 双轴搅拌机：黏土烧结砖生产中的核心混合设备，通过两根平行轴上安装的搅拌桨（或叶片）对黏土、煤矸石、水等原料进行高效均化。适用于高塑性物料的强制搅拌，确保后续挤出成型质量。
- 双轴式搅拌机：每个轴都配有搅拌刀，密封减速箱中充满油，用于保护齿轮并保证功率。搅拌轴座立于轴承座上，驱动设备的电机皮带轮由皮带带动，配有气动离合器。设备的抗压结构独立与搅拌刀，搅拌刀可以替换，保护衬外遁形在基层上，搅拌刀是采用特殊硅钢制成，具有耐磨特性。
- 前置网板挤出机：砖瓦生产线上的一种关键设备，主要用于原料的预处理和初级成型。它位于真空挤出机之前，因此被称为"前置"设备。该设备通过网板对原料进行筛选和初步挤压，为后续的真空挤出成型做准备。

## 砖机挤出机

- 大型真空挤出机：黏土烧结砖生产中的核心设备，主要用于将混合好的黏土原料通过高压挤出成型，并经过真空处理以提高坯体的密实度和强度。其性能直接影响砖坯质量、生产效率和整厂运营稳定性。
- 中型真空挤出机：一款专门针对高端建筑材料半硬塑粘性料的挤出成型设备。该设备材质、技术结构、电器系统、操作系统，均按欧洲标准生产制造。自动化程度高，操作性好。另使用寿命长，节约维护成本。
- 立式螺旋挤出机：引进欧洲最新技术工艺制造。是一款专门针对高端陶瓷材料、水泥制品类以及半硬塑粘性材料的挤出成型设备。该设备材质、技术结构、电器系统、操作系统，均按欧洲标准生产制造。该设备占用空间小，自动化程度高，操作性好。

## 自动化设备

- 双丝架切坯机：以两根同步滚珠丝杠驱动切割框架上下运动的钢丝切坯设备，适坯机用于黏土、页岩、煤矸石等原料制成的湿坯定长切割。采用侧面推坯方式，将切条机输送过来的等长度泥条切割成对应规格的砖块。
- 带倒角切坯机：在传统钢丝切坯机基础上集成倒角刀座的复合设备，可在一次行程中同时完成砖坯定长切断与45°/30°倒角加工，适用于黏土烧结砖、页岩砖、煤矸石砖的湿坯在线整形。
- 下压式切坯机是一种专用于挤出成型砖坯切割工序的自动化设备，属于成型后切割环节的核心机械。它通过垂直下压动作带动切割钢丝（或刀具），将连续挤出的泥条（泥柱）切割成单块砖坯。

## 隧道窑

- 一次码烧干燥工艺：设计在国际上具有较高认可度，尤其适用于追求节省投资、提高自动化、保持生产节奏的中小规模砖厂。尽管其缺乏传统干燥灵活性，但依靠流程集成和节能设计，仍具有较强的竞争力。
- 单层室式干燥：是一种结构紧凑、操作高效的干燥系统，常用于自动化程度较高的砖厂。相比传统的多层干燥架、顶吹/侧吹隧道干燥系统，单层室式干燥在控制精度、空间利用、能耗和产品适应性方面具备显著优势。
- 贯穿式单层隧道干燥室：是一种常见的黏土烧结砖坯体干燥设备。其特点是 坯车从一端进入，沿隧道式干燥通道直线贯穿运行，最后从另一端排出，因此得名“贯穿式”。

## 打包设备

- 机器人打包：一款自动化砖跺打包系统设备，实现全流程自动化作业：机器人精准识别窑车上的红砖，快速完成卸砖动作；通过智能算法规划码垛路径，将砖块整齐堆叠；自动打包环节采用高强度捆扎带，实现无人化打包。
- 多夹头卸砖机：又称卸垛机，是隧道窑烧结砖生产线中用于自动卸砖、理砖、分组、打包的关键自动化设备。该设备通过多夹头同步动作，一次性可完成多垛砖坯的精准抓取与卸放，特别适用于产品规格较少、砖型较为统一的高产量生产线。
- 自动穿箭式捆扎打包系统：是黏土烧结砖厂在成品出窑后进行自动卸砖、分组、码垛与捆扎打包的高端自动化装备。该系统广泛应用于标准砖、KP1砖、保温砌块等多种产品的后段包装环节，是实现砖厂智能化、无人化生产的关键设备之一。

## 制砖技术

1. 隧道窑低热值稀码快烧技法：从原理到关键控制
   - 内燃烧结缺陷多源于码坯过密致供氧不足，稀码本质是回调合理孔隙率以改善渗流；配合低热值策略可降本减排，快烧则需强化风火协同，二者均须与码坯密度动态匹配。综合调控码坯密度、通风阻力、火行速度及热值四参数，方能实现产量、质量与环保的协同最优。
  
2. 二次码烧生产线干燥旋风器原理与核心优势
   - 旋风器是二次码烧砌块、薄壁多孔砖生产线干燥工段的核心设备，主要用于干燥室内动态均匀送风、置换湿空气，有效解决传统干燥吹风不均、坯体干湿失衡、开裂变形等问题，尤其适配高孔洞率、高干燥敏感性砖坯的规模化生产。
  
3. 重粘土工业的节能隧道窑窑车系统
   - 隧道窑窑车系统总是与使用者和产品相联系，知晓未来的厂生产工艺参数如焙烧温度、烧成周期、窑内气氛，而且在设计阶段要考虑生产中的各种条件，以使得有一个正确的选择，可延长系统的使用寿命。只有这样可以避免各种不利因素和不必要的消耗，使系统的选择最佳。
