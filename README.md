# 关于瑞泰

## 企业概况

### 企业简介

1. 西安瑞泰建材科技有限公司成立于2011年，聘请意大利高级工程师并联合国内专家组建了一支具有欧洲技术与中国技术相结合的专业技术团队，为客户提供砖瓦生产工艺设计、工程总承包、机械制造、设备供应及生产运维等全方位专业服务。公司致力于推动砖瓦行业技术进步，引领行业发展方向。

2. 西安瑞泰业务范围：
   - **设计与工程**：
     - 提供全自动砖瓦厂工艺设计及施工建设，涵盖室式/隧道式/快速干燥、隧道窑等。
     - 重点承建干燥室与窑炉工程，保障项目技术达标与产能目标。
   - **机械制造与供应**：
     - **成型包装线**：切坯机、码垛机、全自动卸料打包/包装机、冷拉伸罩膜包装机。
     - **窑炉自动化**：摆渡车、鼓风机、步进机、顶车机、窑车等。
     - **燃烧系统**：气体（天然气/LPG/煤气）、液体（重油/废轮胎油）、固体（煤粉、石油焦、稻壳、棕榈仁壳、椰子壳、棉籽壳等）。
   - **运维保产服务**：
     - 提供砖厂生产调试、运维及保产服务，助力用户轻松稳定生产。

### 瑞泰科技典型案例

1. [伊拉克MUSK日产800吨现代化烧结砌块生产线](https://www.brictec.com/gongchengzhanshi/gcal/292.html)：
   - 西安瑞泰总承包建设伊拉克基尔库克日产800吨砌块工厂，产品涵盖承重砌块、标准砖及隔墙砌块。项目基于Najmadin项目经验，在工艺、设备、能耗及自动化方面均处于行业先进水平，为当地砌块行业树立了典范。

2. [伊拉克KTB日产900吨烧结砖生产线](https://www.brictec.com/gongchengzhanshi/gcal/241.html)：
   - 2025年，西安瑞泰在伊拉克启动KTB烧结砖项目，规划三条隧道窑生产线，分三期推进。一期、二期投产后日产量达900吨，主产240×115×75mm黏土烧结砖，采用先进的隧道窑技术和自动化生产工艺。

3. [马来西亚CBT全自动二次码烧单层干燥工艺多砖型生产线](https://www.brictec.com/gongchengzhanshi/gcal/240.html)：
   - 2024年，西安瑞泰马来西亚CBT项目采用全自动二次码烧单层干燥工艺，生产线日产量为70,000块装饰砖(215×100×67mm)，同时也生产铺地砖、压制砖等多种砖型，充分满足市场多样化需求。

4. [绍兴绿展环保科技有限公司](https://www.brictec.com/gongchengzhanshi/gcal/155.html)：
   - 2023年，西安瑞泰整体设计浙江绿展年产30万方烧结砌块及装配式墙板项目。原料采用本地化工污染土壤、建筑渣土、印染污泥等固废，实现固废资源化利用，体现了绿色环保的发展理念。

5. [伊拉克Najmadin项目](https://www.brictec.com/gongchengzhanshi/gcal/239.html)：
   - 2023年，西安瑞泰与中建材联合设计伊拉克苏莱曼尼省日产750吨烧结砌块项目。原料为页岩，采用二次码烧、隧道干燥室、9米断面隧道窑及重油/LPG双燃料燃烧系统，技术参数达到国际先进水平。

6. [延安绿色建材循环利用产业园仿古砖项目](https://www.brictec.com/gongchengzhanshi/gcal/152.html)：
   - 2022年，西安瑞泰整体设计并主导实施国内装饰砖生产线，产品涵盖仿古青砖、清水墙砖、铺地砖，原料为高品质页岩与紫砂土。生产线集成挤出与压制工艺，产品质量达到国内一流水平。

7. 广东宝丽华电厂高掺量粉煤灰制砖项目：
   - 该项目由西安瑞泰整体设计并主导实施。经多次原料配比实验，最后达到了65%左右的粉煤灰掺配，生产出合格的烧结砖，西安瑞泰在该项目中取得了突破性进展，为电厂固废处理开辟了新途径。

8. [孟加拉ECO CERAMICS项目](https://www.brictec.com/gongchengzhanshi/gcal/104.html)：
   - 西安瑞泰EPC总承包孟加拉GPH集团制砖生产线，采用单层隧道式干燥、两条4.8米隧道窑，配备意大利Bongianni软塑挤出机及瑞泰自研煤粉燃烧器全自动外燃系统，项目运行效果显著。

9. 乌兹别克斯坦卡德尔项目：
   - 西安瑞泰为乌兹别克斯坦排名前三的高端制砖企业的两条生产线提供全套自动化切码运装备及天然气燃烧系统，客户评价其为"值得信赖的合作伙伴"。

## 发展历程

1. 2026年
   - MUSK 项目位于伊拉克基尔库克，规划建设一座日产 800 吨的现代化砌块生产基地，产品涵盖承重砌块、标准砖及隔墙砌块，能够满足当地多类建筑结构的用材需求，为区域城市建设提供稳定、高品质的材料供应

2. 2025年
   - 西安瑞泰2025年将在伊拉克启动第二个重大工程项目——KTB烧结砖生产线项目。该项目规划建设3条现代化烧结砖生产线(240*115*75mm)，分三期实施。其中，一期和二期投产后，预计每日总产量可达900吨。
  
3. 2024年
   - 马来西亚CBT装饰砖生产线项目是西安瑞泰2024年着力打造东南亚示范砖厂工程项目，按照项目生产工艺设计日产7万块装饰砖（215x100x67mm）生产线。
  
4. 2023年
   - Najmadin 项目于2023年由西安瑞泰及中建材联合设计实施，设计日产750吨烧结砌块，项目位于伊拉克苏莱曼尼省，原料采用页岩，西安瑞泰参与项目工艺设计，调试各个环节，采用二次码烧，隧道干燥室，9米断面隧道窑，重油/液化石油气双燃料烧成，在伊拉克与欧洲同行竞争，展现了中国技术实力，目前项目已投产。

5. 2023年
   - 浙江绿展年产30万方烧结砌块及装配式墙板项目，由西安瑞泰全程设计并供应核心装备。原料采用本地化工污染土壤、建筑渣土、印染污泥等固废，实现资源化利用；屋顶光伏满足60%~70%生产用电。工艺采用二次码烧、隧道室干燥、7米断面隧道窑及全天然气燃烧器焙烧，为固废制砖提供标杆案例。

6. 2022年
   - 西安瑞泰总承包延安仿古砖项目，以页岩、紫砂土为原料，集成挤出与压制成型，采用室式干燥及天然气窑炉烧制，自动化水平国内领先。

7. 2021年
   - 瑞泰在哈萨克斯坦WG项目工程，该项目采用压制成型工艺，天然气烧成，提供全套自动化切码运装备，公司员工顶着疫情的压力，坚持为客户提供安装调试服务。
  
8. 2020年
   - BAHA项目已投产运营。新砖厂从原料处理、成型、干燥、隧道窑焙烧等环节，工艺设计和施工建设均由西安瑞泰负责。BAHA砖厂建成后，在哈特隆地区属于具有先进水平的自动化烧结砖厂。
  
9. 2019年
   - 瑞泰承接的孟加拉GPH集团ECO CERAMICS项目顺利投产，采用二次码烧工艺、意大利BONGIANNI对辊机与挤出机，配套瑞泰自研煤粉燃烧系统。该集团为孟加拉大型建材制造商，旗下涵盖水泥及钢铁产业，新砖厂将成为该国产量与工业化程度领先的产线。同年，Pretty、USHA、ALPHA项目相继交付。
  
10. 2018年
    - 2月，新型装配式隧道窑获国家发明专利；4月，承包经营山东矿机迈科，当年业绩翻番；7月，代表中国制砖业参展德国慕尼黑陶瓷工业展；10月，首条瑞泰天然气燃烧系统技改隧道窑顺利投产。

12. 2017年
    - 2017瑞泰在孟加拉承接的SAS项目二次码烧“交钥匙工程”顺利投产，该项目两条隧道窑采用意大利BERNINI煤粉燃烧器全外燃烧成，项目投资超过1000万美金，项目的顺利交付，标志着瑞泰在高端制砖生产线技术达到国际水平。

13. 2016年
    - 2016年公司研发的超高掺量粉煤灰生产烧结砖的工艺获得国家发明专利，当年与意大利FRAC公司合作，引进天然气燃烧器系统。

14. 2014-2015年
    - 2014年瑞泰在孟加拉先后完成COMPREHENSIVE 项目，G.S.A项目，吉大港S.B 项目等，在项目经验上积累丰富的经验，国内的技术团队与孟加拉本地团队实现较完美的分工与合作。
2015年瑞泰在孟加拉完成三个项目，在印度依托孟加拉施工团队完成两个项目。

15. 2013年
    - 西安瑞泰在孟加拉与本地员工合资成立分公司，在土化团队的建设及提供本地化服务方面开辟了一条成功的道路，瑞泰在孟加拉业务进入高速发展期，为未来几年成功交付二十多个项目奠定了坚实的基础。

16. 2012年
    - 西安瑞泰在孟加拉国承建第一条隧道窑工程（Conforce项目），该项目设计为2.5米宽断面的平顶隧道窑，在孟加拉属于早期的一条隧道窑之一，至今仍然正常生产。

17. 2011年
    - 西安瑞泰成立于2011年，以“一站式砖厂解决方案”为使命，依托西安技术底蕴，联合意大利高级工程师组建中欧融合团队，为客户提供建筑砖、装饰砖、压制烧结砖等专业解决方案。
