# 关于瑞泰
## 企业概况
### 企业简介
1. 西安瑞泰建材科技有限公司成立于2011年，聘请意大利高级工程师并联合国内专家组建了一支具有欧洲技术与中国技术相结合的专业技术团队，为客户提供制砖的技术解决方案，包括装建筑砖、装饰砖、干挂外墙砖、铺路砖、压制烧结砖等的解决方案；
2. 西安瑞泰业务范围：
- 设计与工程：
  - 提供全自动砖瓦厂工艺设计及施工建设，涵盖室式/隧道式/快速干燥、隧道窑等。
  - 重点承建干燥室与窑炉工程，保障项目技术达标与产能目标。
- 机械制造与供应：
  - **成型包装线**：切坯机、码垛机、全自动卸料打包/包装机、冷拉伸罩膜包装机；
  - **窑炉自动化**：摆渡车、鼓风机、步进机、顶车机、窑车等；
  - **燃烧系统**：气体（天然气/LPG/煤气）、液体（重油/废轮胎油）、固体（煤粉、石油焦、稻壳、棕榈仁壳、椰子壳、棉籽壳等）。
- 运维保产服务
  - 提供砖厂生产调试、运维及保产服务，助力用户轻松稳定生产。
### 瑞泰科技典型案例：
1. [伊拉克MUSK日产800吨现代化烧结砌块生产线](https://www.brictec.com/gongchengzhanshi/gcal/292.html)：
- 西安瑞泰总承包建设伊拉克基尔库克日产800吨砌块工厂，产品涵盖承重砌块、标准砖及隔墙砌块。项目基于Nanjmadin项目经验，在工艺、设备、能耗及品控上全面升级，实现高自动化、高精度与高效用能。全线采用LPG清洁燃料，降低排放与运行负荷。按国际先进标准设计，融合中国制造与欧洲技术，建成后将成为区域标杆，助力伊拉克重建，展现中国工程企业的海外实力。
2. [伊拉克KTB日产900吨烧结砖生产线](https://www.brictec.com/gongchengzhanshi/gcal/241.html)：
- 2025年，西安瑞泰在伊拉克启动KTB烧结砖项目，规划三条隧道窑生产线，分三期推进。一期、二期投产后日产量达900吨，主产240×115×75mm黏土烧结砖。该项目将进一步巩固瑞泰在中东市场地位，助力伊拉克建材产业升级。
3. [马来西亚CBT全自动二次马少单层干燥工艺多砖型生产线](https://www.brictec.com/gongchengzhanshi/gcal/240.html)：
- 2024年，西安瑞泰马来西亚CBT项目采用全自动二次码烧单层干燥工艺，生产线日产量为 70,000 块装饰砖 (215× 100 × 67mm)，同时也生产铺地砖，压制砖等多砖型。
4. [绍兴绿展环保科技有限公司](https://www.brictec.com/gongchengzhanshi/gcal/155.html)：
- 2023年，西安瑞泰整体设计浙江绿展年产30万方烧结砌块及装配式墙板项目。原料采用本地化工污染土壤、建筑渣土、印染污泥等固废，实现固废资源化；屋顶光伏发电满足60%~70%生产用电。工艺采用二次码烧、隧道室干燥、7米断面隧道窑，全天然气烧成。瑞泰全程参与规划、设计及核心装备供应，为行业贡献了固废制砖的标杆案例。
5. [伊拉克Najmadin项目](https://www.brictec.com/gongchengzhanshi/gcal/239.html)：
- 2023年，西安瑞泰与中建材联合设计伊拉克苏莱曼尼省日产750吨烧结砌块项目。原料为页岩，采用二次码烧、隧道干燥室、9米断面隧道窑及重油/LPG双燃料系统。瑞泰全程参与工艺设计与调试，项目已顺利投产，在与欧洲同行竞争中充分展现了中国工程技术实力。
6. [延安绿色建材循环利用产业园仿古砖项目](https://www.brictec.com/gongchengzhanshi/gcal/152.html)：
- 2022年，西安瑞泰整体设计并主导实施国内装饰砖生产线，产品涵盖仿古青砖、清水墙砖、铺地砖，原料为高品质页岩与紫砂土。生产线集成挤出与压制成型，采用室式干燥、天然气隧道窑及三座梭式窑，瑞泰提供从工艺设计、干燥室建造、设备供应到生产调试的全流程服务。该生产线自动化程度国内领先，达行业先进水平。
7. 广东宝丽华电厂高掺量粉煤灰制砖项目：
- 该项目由西安瑞泰整体设计并主导实施经多次原料配比实验，最后达到了65%左右的粉煤灰掺配，生产出合格的烧结砖，西安瑞泰在该项目中取得了高掺量粉煤灰制砖的发明专利（专利号：ZL 2014 1 0352207.5）。
8. [孟加拉ECO CERMICS项目](https://www.brictec.com/gongchengzhanshi/gcal/104.html)：
- 西安瑞泰EPC总承包孟加拉GPH集团制砖生产线，采用单层隧道式干燥、两条4.8米隧道窑，配备意大利Bongianni软塑挤出机及瑞泰自研煤粉燃烧器全自动外燃系统。该项目建成后成为孟加拉自动化程度及规模领先的制砖线，屋顶光伏发电可满足生产线60%用电需求。
9. 乌兹别克斯坦卡德尔项目：
- 西安瑞泰为乌兹别克斯坦排名前三的高端制砖企业的两条生产线提供全套自动化切码运装备及天然气燃烧系统，客户评价其为“值得信赖的合作伙伴”，并称赞燃烧系统较欧洲产品操作更简便、更节能。二期项目中，瑞泰协助引入废旧轮胎裂解油用于焙烧，保障砖品质量的同时显著降低成本。瑞泰将持续创新，为客户定制多元制砖解决方案。
